## 🧱 Task 1: Page Structure (HTML – Practical)

Create a simple web page that contains:
- A title
- A heading
- A paragraph
- A button

### Your Task

- What the **title** is used for

- What a **button** is commonly used for

## 🎨 Task 2: Text Styling (CSS – Practical)

Apply styling to text by:
- Changing the text color
- Adjusting the font size
- Selecting a font family
- Centering the text
- Making the heading text uppercase

### Your Task
For each change, write **1–2 lines** explaining:
- What you changed
- How it affected the appearance of the text

⚠️ *Challenge:* Do not mention property names directly — describe the effect instead.

## 📦 Task 3: Box Model (CSS – Practical)

Improve the appearance of content by:
- Adding space inside the content
- Adding space outside the content
- Adding a visible border
- Making the corners rounded

### Your Task
Explain:
- How spacing changes the layout
- How borders affect visibility
- Why rounded corners improve design

⚠️ *Think:* How does spacing help readability?
